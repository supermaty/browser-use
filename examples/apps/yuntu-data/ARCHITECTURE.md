# Yuntu-Data 应用架构说明

## 📋 整体概览

Yuntu-Data 是一个基于 Browser Use 的自动化数据抓取应用，通过 Gradio 界面接收用户自然语言任务，自动登录巨量云图网站，抓取营销复盘数据，并生成标准化的 Excel 报表。

### 期望流程（两步）

1. **按取数路径获取数据**：提示词中只描述「取数路径」与目标数据项，Agent 在云图页面上按路径操作并获取数据，**不要求** Agent 输出特定文本格式。
2. **按模板格式导出**：用「从 sample 文件（【黑玩】赛马复盘0105.xlsx）分析得到的输出格式」将取到的数据填入 **黑玩赛马复盘-template.xlsx**，生成新 Excel；导出时**完全遵照模板**中的行列与样式，不依赖提示词里的输出格式。

## 🔄 详细流程说明

### 1. 用户输入处理

**入口**：`app.py::process_task_generator()`

- 用户通过 Gradio 界面输入自然语言任务，例如：
  > "从巨量云图中帮我获取一下黑玩的复盘数据，报告名：ZY-SHK12.1-12.31；行业搜索洞察的日期范围是：自定义（2025/12/01-2025/12/31）"

- 系统提取最后一条用户消息，调用 `extract_intent()` 进行意图识别

### 2. 意图提取

**模块**：`intent.py`

- 使用 Gemini LLM（`gemini-3-pro-preview`）解析用户输入
- 提取关键信息：
  - `report_name`: 报告名称（如 "ZY-SHK12.1-12.31"）
  - `brand_name`: 品牌名称（如 "黑玩"）
  - `insight_date_range`: 日期范围字符串（如 "自定义（2025/12/01-2025/12/31）"）
  - `date_range_type`: 日期类型（如 "自定义"、"近7天"、"近30天"等）
- 支持多轮对话：保留之前提取的值，除非新消息提供了新值
- 输出：`YuntuTask` Pydantic 模型

### 3. 参数验证

**位置**：`app.py::process_task_generator()`

- 检查必需字段：
  - 报告名必须存在
  - 日期范围和日期类型必须存在（用于行业搜索洞察）
- 如果缺失，返回错误提示，要求用户补充

### 4. 登录检查

**模块**：`login.py`

- 检查浏览器 profile 目录是否存在（`browser_profiles/yuntu_profile/`）
- 检查 `storage_state.json` 是否存在（包含 cookies）
- 如果不存在：
  - 打开浏览器，引导用户手动登录巨量云图
  - 登录成功后保存 `storage_state.json`
- 如果已存在：直接复用，跳过登录步骤

### 5. 提示词组装

**模块**：`config.py`

- 根据品牌名称选择模板：
  - 如果品牌名包含 "黑玩" → 使用 `HEYONE_PROMPT_TEMPLATE`
  - 否则 → 使用 `GENERIC_PROMPT_TEMPLATE`
- 使用 `.format()` 填充变量：
  - `{report_name}` → 报告名称
  - `{insight_date_range}` → 日期范围
  - `{date_range_type}` → 日期类型
- 生成最终提示词，传给 Agent

### 6. Agent 执行

**模块**：`app.py` + Browser Use Agent

- 创建 `Browser` 实例：
  - `user_data_dir`: 复用登录 profile
  - `storage_state`: 加载 cookies
  - `downloads_path`: 指定下载目录
  - `headless=False`: 显示浏览器窗口（便于调试）
- 创建 `Agent` 实例：
  - `task`: 组装好的提示词
  - `llm`: ChatGoogle（Gemini 模型）
  - `browser`: Browser 实例
  - `flash_mode=False`: 使用完整推理模式
- Agent 执行流程（由提示词驱动）：
  1. 打开巨量云图网站
  2. 切换到指定品牌账号
  3. 进入「营销决策」→「投后结案」
  4. 搜索并打开目标报告
  5. 在各个模块中提取数据：
     - 流量分析：曝光次数、互动率、完播率
     - 人群分析：A3流转人数、A3流转率、拉新人群规模
     - 转化分析：本次活动转化金额
     - 搜索分析：回搜次数、7日回搜人数
  6. 下载 Excel 文件（达人及内容复盘、投流数据精细化复盘）
  7. 输出结构化文本结果
- 实时日志：通过 `on_step_start` 和 `on_step_end` 回调，实时更新 Gradio UI

### 7. 数据提取

**模块**：`data_extractor.py`

- 从 `AgentHistoryList` 中提取：
  - `final_result()`: Agent 的最终输出文本
  - `extracted_content()`: 所有提取的内容列表
- 使用正则表达式匹配各个字段：
  - **项目整体**：`_extract_project_overview()`
    - 匹配模式：`r'消耗金额[：:]\s*([^\n]+)'` 等
    - 解析数字：使用 `parse_number()` 处理百分比、千分位等格式
  - **5A人群流转**：`_extract_a5_asset_flow()`
  - **搜索洞察**：`_extract_search_insight()`
  - **TA画像**：`_extract_ta_portrait()`（提取文本段落）
- 输出：`YuntuDataReport` 对象，包含所有模块的数据

### 8. Excel 文件处理

**模块**：`excel_processor.py`

- **扫描下载目录**：
  - 使用 `find_downloaded_excel_files()` 查找最近 24 小时内下载的 Excel 文件
- **识别文件类型**：
  - 使用 `identify_excel_file_type()` 根据文件名判断：
    - 包含 "达人"、"内容"、"KOL" → `kol_content`
    - 包含 "投流"、"人群包"、"AdFlow" → `ad_flow`
- **读取 Excel**：
  - **达人及内容复盘**：`read_kol_content_excel()`
    - 使用 `pandas.read_excel()` 读取所有 sheet
    - 查找包含 "曝光"、"互动"、"CPM"、"CPE"、"CPA3" 的列
    - 提取达人效率对比数据
    - 计算爆文率（基于完播率阈值）
  - **投流数据精细化复盘**：`read_ad_flow_excel()`
    - 查找包含 "人群包"、"A3"、"CPA3" 的列
    - 提取人群包表现数据
    - 计算平均 A3 流转率
- **更新报告**：
  - 创建 `KOLContentReview` 和 `AdFlowReview` 对象
  - 更新 `YuntuDataReport` 中的对应字段

### 9. 指标计算

**模块**：`excel_processor.py::calculate_metrics()`

- 如果 `ProjectOverview` 中某些成本指标缺失，自动计算：
  - **CPM** = 消耗金额 / 曝光次数 × 1000
  - **CPE** = 消耗金额 / 互动量
  - **CPS** = 消耗金额 / 回搜次数
  - **CPA3** = 消耗金额 / A3流转人数
  - **ROI** = 本次活动转化金额 / 消耗金额
- 补充到 `ProjectOverview` 模型中

### 10. Excel 导出

**模块**：`excel_exporter.py`

#### 模式 1：模板模式（优先）

- **检查模板文件**：
  - 默认导出模板：`docs/黑玩赛马复盘-template.xlsx`（写入数据用）
  - 对比标准：`docs/【黑玩】赛马复盘0105.xlsx`（仅作参考，不修改）
  - 如果存在，优先使用模板模式
- **加载模板**：
  - 使用 `openpyxl.load_workbook()` 加载模板（`data_only=False` 保留公式）
- **写入数据**：
  - **总体数据表现 sheet**：
    - 使用 `_project_overview_to_template()` 函数
    - 扫描 1-20 行，找到包含 "报告名字" 的表头行
    - 构建 `header_map`（表头文字 → 列索引）
    - 找到表头下方的第一行数据行（TTL 行）
    - 按表头精确匹配，写入 `ProjectOverview` 数据：
      - "报告名字" → `report.报告名称`
      - "消耗金额" → `project.消耗金额`
      - "曝光次数" → `project.曝光次数`
      - "A3流转率" → `project.A3流转率`
      - 等等...
    - **保持格式不变**：只修改单元格值，不改变样式、合并单元格、公式
- **保存文件**：
  - 保存到 `data-output/excel_exports/`
  - 文件名：`品牌名_报告名_时间戳.xlsx`

#### 模式 2：标准模式（回退）

- 如果模板文件不存在或加载失败，回退到标准模式
- **创建新 Workbook**：
  - 删除默认 Sheet
- **创建各个 sheet**：
  - `_create_project_overview_sheet()`: 项目整体（两列：指标、数值）
  - `_create_a5_asset_flow_sheet()`: 5A人群资产流转
  - `_create_kol_content_sheet()`: 达人及内容复盘
  - `_create_search_insight_sheet()`: 搜索与溢出价值
  - `_create_ad_flow_sheet()`: 投流数据精细化复盘
  - `_create_ta_portrait_sheet()`: TA人群画像精准度复盘
  - `_create_summary_sheet()`: 汇总信息
- **应用样式**：
  - 蓝色表头（`#366092`）
  - 白色加粗字体
  - 居中对齐
  - 自动调整列宽

### 11. UI 反馈

**位置**：`app.py::process_task_generator()`

- 显示任务摘要：
  - 报告名、品牌、日期范围
- 显示 Agent 执行日志：
  - 实时更新步骤信息
  - 显示执行的动作、思考过程、提取的内容
- 显示最终结果：
  - 任务完成状态
  - Excel 文件路径
  - Agent 的最终输出文本

## 🔑 关键设计决策

### 1. 多轮对话支持

- **问题**：用户可能分多次提供信息（先给报告名，再给日期范围）
- **解决**：使用全局变量 `_session_intent` 保存已提取的意图，在下一轮对话中合并新值

### 2. 模板模式 vs 标准模式

- **问题**：需要生成与业务标准格式完全一致的 Excel
- **解决**：
  - 优先使用模板模式，保持格式、样式、结构完全一致
  - 如果模板不存在，回退到标准模式，保证功能可用

### 3. 数据来源多样性

- **问题**：数据可能来自页面文本、下载的 Excel、计算得出
- **解决**：
  - 页面数据：通过 Agent 提取文本，正则解析
  - Excel 数据：扫描下载目录，pandas 读取
  - 计算数据：基于已有数据自动计算缺失指标

### 4. 错误处理

- **问题**：Agent 执行、数据提取、Excel 导出都可能失败
- **解决**：
  - 每个步骤都有 try-except 包裹
  - 失败时不影响主流程，返回错误信息给用户
  - Excel 导出失败时，至少保证 Agent 执行结果可用

### 5. 实时反馈

- **问题**：Agent 执行时间较长，用户需要知道进度
- **解决**：
  - 使用 `on_step_start` 和 `on_step_end` 回调
  - 定期更新 Gradio UI（每 0.5 秒检查一次）
  - 显示步骤数、执行动作、思考过程

## 📝 使用示例

### 完整流程示例

1. **用户输入**：
   > "从巨量云图中帮我获取一下黑玩的复盘数据，报告名：ZY-SHK12.1-12.31；行业搜索洞察的日期范围是：自定义（2025/12/01-2025/12/31）"

2. **系统处理**：
   - 提取意图：报告名="ZY-SHK12.1-12.31"，品牌="黑玩"，日期范围="自定义（2025/12/01-2025/12/31）"
   - 检查登录状态（已登录，跳过）
   - 选择黑玩模板，组装提示词
   - Agent 执行：打开网站 → 切换账号 → 找到报告 → 提取数据 → 下载 Excel
   - 数据提取：从 Agent 输出解析结构化数据
   - Excel 处理：读取下载的 Excel，提取达人/投流数据
   - 指标计算：计算 CPM、CPE、CPA3、ROI
   - Excel 导出：使用模板模式，生成报表

3. **输出结果**：
   - Excel 文件：`data-output/excel_exports/黑玩_ZY-SHK12.1-12.31_20250128_143022.xlsx`
   - UI 显示：任务完成，文件路径，执行日志

## 🔧 配置说明

### 环境变量（.env）

- `GOOGLE_API_KEY`: Gemini API 密钥（必需）
- `BROWSER_PROFILE_DIR`: 浏览器 profile 目录（可选，默认：`browser_profiles/yuntu_profile`）
- `BROWSER_DOWNLOADS_PATH`: 下载目录（可选，默认：`downloads`）

### 配置文件（config.py）

- `GEMINI_MODEL`: 使用的 Gemini 模型（默认：`gemini-3-pro-preview`）
- `HEYONE_PROMPT_TEMPLATE`: 黑玩专属提示词模板
- `GENERIC_PROMPT_TEMPLATE`: 通用提示词模板
- `EXCEL_OUTPUT_DIR`: Excel 输出目录（默认：`data-output/excel_exports`）
